# 업무 규칙·함정 정리 보고: HotDealWave

이슈 #23에서 업무 규칙 Skill 6절 정리를 두 번째로 실행한 Codex 세션의 보고 원문이다. 실행 환경 문장과 로컬 경로 링크만 지웠다. 항목 번호는 정리 전 서비스 파일의 `items` 순서(1부터)다. 결과 요약과 대조는 [5단계 보고서](rules-hotdealwave.md) 7절에 있다.

정리를 완료했습니다. **항목은 125개 → 127개**, **검증기 경고는 13개 → 11개**입니다. 허용된 `knowledge/hotdealwave/*.json` 7개만 수정했고 커밋하지 않았습니다.

| 파일 | 정리 전 | 정리 후 |
|---|---:|---:|
| `company-service.json` | 8 | 7 |
| `coupon-service.json` | 18 | 19 |
| eureka-server.json | 0 | 0 |

아래 번호는 **정리 전 `items` 순서**입니다. 서비스 이름의 `-service`는 생략했습니다.

합치기·나누기·종류 변경은 다음과 같습니다.
