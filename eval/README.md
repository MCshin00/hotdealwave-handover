# 평가 자료

| 파일 | 내용 | 쓰는 쪽 |
|---|---|---|
| `questions/final.csv` | 최종 비교 질문. 지금 실제로 궁금한 것을 쓰고, 도구 결과를 보기 전에 고정한다 | 개발자 |
| `questions/tuning.csv` | 도구를 고칠 때 쓰는 질문 | 개발자·AI |
| `facts.csv` | 교차 검증 경고를 판정한 사실 목록 | 경고는 도구, 판정은 개발자 |
| `results/` | 판정 집계와 비교 실험 결과 | AI가 정리, 개발자가 확인 |

최종 질문은 구현·검토 작업에서 열지 않고, 검색 색인·프롬프트·테스트 기대값에 넣지 않는다.

## 최종 질문 열

| 열 | 값 |
|---|---|
| `id` | `Q01`, `Q02`, … |
| `질문` | 실제로 물을 문장 그대로 |
| `종류` | API 스펙, 흐름, 저장소 밖(답할 수 없어 보류해야 하는 질문) |
| `메모` | 자유 |

질문을 쓸 때 참고할 흐름: 주문 생성(상품 조회와 재고 차감), 주문 취소·환불과 결제, 재고 차감 실패 롤백, 상품 이미지 업로드.

## 사실 목록 열

| 열 | 값 |
|---|---|
| `id` | `F1`, `F2`, … |
| `교차 검증` | 선언 목록, Feign↔컨트롤러, 게이트웨이↔컨트롤러, 발행↔구독 |
| `종류` | REST, Feign, Kafka, 설정, 외부 자원 |
| `출발` | 서비스와 `파일:줄` |
| `도착` | 서비스와 `파일:줄`, 없으면 비움 |
| `도구 결과` | 도구가 낸 상태와 경고 |
| `판정` | 추출 오류, 코드의 실제 어긋남, 확인 안 됨 유지 |
| `실제 연결` | 예, 아니오, 모름 |
| `판정 근거` | 코드 확인, 실제 응답 |
| `근거 파일:줄` | 여러 개는 `;`로 구분 |
| `메모` | 자유 |
