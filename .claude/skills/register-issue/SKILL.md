# 이슈 등록

1. 개발자가 준 문제와 근거를 확인한다. 단계 작업이면 [docs/progress.md](../../../docs/progress.md)의 해당 단계와 [docs/decisions.md](../../../docs/decisions.md)의 관련 결정을 읽는다.
2. [개발 작업 양식](../../../.github/ISSUE_TEMPLATE/development.md)을 그대로 복사해 초안을 시작하고 각 절을 채운다. 해당 없는 선택 절만 지운다. 확인 조건은 대표 사례만 쓰고, 상태 표시 규칙에서 나오는 경우("확인 안 됨", "저장소에 근거 없음")를 넣는다.
3. `gh label list`의 설명을 보고 맞는 종류 라벨 하나를 골라 초안과 함께 개발자에게 보여 준다. 맞는 라벨이 없으면 억지로 고르지 말고 알린다. 개발자가 확인 조건을 빼거나 더한다.
4. 개발자가 좋다고 하면 `gh issue create`로 등록하고, 고른 라벨이 있으면 `--label "<고른 라벨>"`을 쓴다.
